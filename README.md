\# Task 31 - Secure File Upload API



A secure file upload REST API developed using FastAPI as part of the VEDA Technology Level 2 internship.



\## Features



\- Secure file upload endpoint

\- File extension validation

\- MIME type validation

\- File signature validation

\- Maximum file size of 5 MB

\- Executable file blocking

\- UUID-based secure filenames

\- Dedicated upload directory

\- Error handling for invalid uploads



\## Technologies Used



\- Python

\- FastAPI

\- Uvicorn

\- python-multipart



\## Allowed File Types



The API supports:



\- `.jpg`

\- `.jpeg`

\- `.png`

\- `.pdf`

\- `.txt`



Maximum file size: \*\*5 MB\*\*



\## Security Measures



\### 1. Extension Validation



Only approved file extensions are accepted.



\### 2. MIME Type Validation



The uploaded file's content type is checked against an allowed list.



\### 3. File Signature Validation



Binary files are checked against their expected file signatures.



\### 4. Executable File Blocking



Executable extensions such as `.exe`, `.bat`, `.cmd`, `.msi`, `.sh`, `.ps1`, `.vbs`, and `.js` are rejected.



\### 5. File Size Restriction



Files larger than 5 MB are rejected.



\### 6. Secure Filenames



The original filename is not used for storage. A UUID-based filename is generated by the server.
